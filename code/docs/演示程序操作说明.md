# 车载 POI 动态推送系统 · 演示程序操作说明

> 更新日期: 2026-11-16（对应提交 1d72074）

## 一、产品是什么

一个完整的车载兴趣点动态推送演示程序（前端 Vue 单页 + 后端 FastAPI 真实决策链）。
系统在"对的时刻、以安全的方式把对的 POI 推给车里的人"：唯一端侧模型双通道——**MLP 说数字**
（预测司机当前最需要的 POI 类别）+ **JSON prompt 说句子**（LLM 从附近合规候选中定稿），
约束引擎四规则做安全门控（疲劳等级 / 深夜营业时间 / 高速禁推目的地型 / 15 分钟冷却）。

## 四、用法一：静态点选分析（调试/现场问答）

1. 顶栏选用户、改时间（默认最后一天 10:30）
2. 点击地图任意位置设置车辆位置（周边 POI 自动加载）
3. 点 **⚡一键决策** → 右侧滑出推送卡（或拦截卡），底部步骤条可展开看每一步中间产物
4. 改左面板"道路等级=高速"再决策，可看到目的地型 POI 被拦（高速禁推规则）

## 五、用法二：行驶回放（主形态，含回放评测）

1. 顶栏选用户（默认 **U_318**），回放控制条选日期（默认 **2008-02-04**，演示推荐天）
2. 点 **▶ 播放**：车辆沿该用户当日真实 GPS 轨迹贴路行驶（A* 沿路网连线，匀速播放——
   速度档 = 模拟分钟/真实秒，车速视觉恒定；时间加速，默认 2 模拟分钟/秒）
3. 每累计 **20 模拟分钟**触发一次完整决策：
   - 绿色卡 = 推送（含名字/类别/距离/理由 + 📊MLP 预测数字 + ⚖️约束结论；若司机 3 小时内真去了同类 POI，显示 **✓ 事后验证**）
   - 红色卡 = 被约束拦截（原因按规则归并显示，并显示"模型本来想推"的预测类别）
   - 静默 = 无合规候选 / 同 POI 冷却（不弹卡，只计数）
   - 左上角常驻预测条显示最近一次决策的 MLP 说数字结果
4. 播完自动停（按钮变 **▶ 重播**），结束提示给出 推/拦/静 计数与判卷命中率
5. 实时计分：顶栏计数"判卷 N / 命中 M"——离线 300 用户同口径成绩为 全体 59.6% / 验证集 49.7%（2026-11-21 修复训练标签泄漏后的口径）

参数：速度 1/2/5/10 模拟分钟每秒；跟随视角开关；回放中不可换日期，先 ■ 停止再换。

## 六、疲劳感知演示（安全门控）

1. 左面板"疲劳感知 → 场景"选 **困倦（30帧）**：真实推理预置帧（PERCLOS → 安全等级 L2）
2. 再点 ⚡一键决策 或继续回放 → 只放行 停车/如厕/便利店/服务区 类，其余全部拦截（红卡）
3. 选 **清醒（30帧）** 恢复 L0。推理约 18s/30 帧（mp-env 子进程，一次性体验）

## 十、回放评测怎么判卷（口径与推送时机）

**判卷口径**：决策点每 20 模拟分钟一个；判卷答案 = 决策时刻**之后** 3 小时内司机真实到达的
第一个停留点；命中 = MLP top3 包含该停留的类别。答案严格取决策后的停留，因此
**预测永远先于答案**——每次判卷检验的都是"系统能否提前预知司机接下来要干什么"。

**预测提前量分布**（决策时刻 → 司机真实到达的时间差，20,229 个有答案决策点，
脚本 `model/lead_time.py` 可复算，结果存 `data/model/lead_time.json`）：

| 指标 | 全体 | 验证集 |
|---|---|---|
| 中位数 | 76 分钟 | 77 分钟 |
| 四分位 | 36 ~ 125 分钟 | 37 ~ 125 分钟 |
| 提前 ≥5 分钟 | 98.9% | 99.1% |
| 提前 ≥15 分钟 | 91.3% | 91.6% |
| 提前 ≥30 分钟 | 80.4% | 80.9% |

九成以上预测在司机到达前至少 15 分钟给出——预测能力真实存在，不是事后贴金。
另一面：96,367 个决策点中只有 21.0% 在 3 小时内真有 POI 停留，司机大部分时间在路上，
系统多数时刻保持安静（"静"计数）正是"该推才推"的设计。

**定频 vs 事件驱动**：固定 20 分钟间隔是演示用的简化——它不保证"到达该区域前恰好
给出推送"的完美时机（提前 76 分钟可能太早，真到眼前时冷却期未过、下一个 tick 未到）。
真实车载推送系统是**事件驱动**的：

| 触发方式 | 场景 | 保证 |
|---|---|---|
| 进入服务半径 | 距 POI 800m 内才做"推不推"决策 | 推送永远在到达前 |
| 沿路前方提示 | 导航路线上前方 N 公里有服务区/加油站 | 提前量与车速挂钩 |
| 需求信号 | 油量低 / 连续驾驶超时 / 疲劳升档 | 时机即需求时刻 |
| 定频兜底 | 20 分钟一次防长时间沉默 | 保底 |

**改进方向（待办）**：回放决策触发改"定频 + 事件混合"（进入 POI 服务半径立即决策）；
新增时机指标（推送时刻距目标 POI 的距离/预计到达时间分布），与预测准确率并列。
